# Mäkko — e-shop postielok

Jednoduchá responzívna landing page / e-shop obliečok vytvorená v čistom HTML, CSS a JavaScripte.

## Spustenie

Najjednoduchšie otvoríš `index.html` v prehliadači. Na lokálny server môžeš použiť:

```bash
python -m http.server 8000
```

Potom otvorí `http://localhost:8000`.

## Obsah

- responzívny dizajn pre mobil, tablet aj desktop,
- 8 produktov s filtráciou podľa materiálu,
- vyhľadávanie produktov,
- detail produktu v modálnom okne,
- košík s množstvom, údajom o doprave a uložením do `localStorage`,
- newsletter formulár, FAQ sekcia a responzívne menu.

Produkty, texty, farby a odkazy na obrázky sa dajú meniť priamo v `index.html` a `styles.css`.
